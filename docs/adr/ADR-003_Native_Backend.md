# ADR-003 — optional pinned native backend

Date: 2026-09-10. Decision: implement a bounded optional Galvani adapter for research use, preserving P01 and the text importer. This supersedes the earlier decision to leave Galvani evaluation-only. It does not select the final application distribution license or claim complete native compatibility.

Inspected source: [Galvani BioLogic module at the evaluated revision](https://github.com/echemdata/galvani/blob/d4a5f444b16eae57d2edfad6df774ead95c92fd6/galvani/BioLogic.py), its constructor, module/column handling, flag access, sidecar fallback, license header and package metadata. That revision's package metadata says 0.5.0 and source license is GPL-3.0-or-later. NumPy 2.3.5 was available and executed. The [repository README](https://github.com/echemdata/galvani) points development to Codeberg. Codeberg remained inaccessible to browsing due to robots restrictions, so this is a tested pinned revision, not a claim to the latest upstream version.

The inspected constructor can load neighboring loop/log files when a path is supplied. Supplying an in-memory stream can reach fallback path variables that were not initialized. The adapter therefore uses an isolated temporary directory and never supplies implicit sidecars. Unknown-column dtype guessing is disabled, and Python optimized mode is rejected because the upstream reader uses assertions for some layout checks. These decisions follow inspected code and are exercised in adapter tests.

Why this candidate: the prior paired-file probes and the new byte/record/corruption checks provide concrete evidence for a limited path without introducing a second independently maintained binary parser. The adapter retains raw modules, field locations, IDs and flags, while leaving incomplete metadata interpretation explicit. Yadg remains a candidate if broader metadata coverage justifies its dependencies and passes a separately pinned comparison; its prior review was documentation-only and is not newly represented as runtime-tested.

The dependency is imported only by native operations. Text import and stored-project reopening remain usable without it. Fingerprints pin both `BioLogic.py` and the package initializer, plus the tested NumPy version. This is a compatibility gate, not an authenticity or sandbox security guarantee. Changing the pin requires documented review and rerunning relevant compatibility cases.

Galvani code is not copied into this source bundle; the optional requirements file identifies the exact dependency. GPL distribution obligations still matter when incorporating that dependency, regardless of optional loading. Application license selection, complete notices and final distribution review remain release work. No public distribution of a compiled application or upstream modification was performed.

Public binary fixtures are unmodified copies from the same revision's `tests/testdata`. Its dataset notice declares CC-BY-4.0. The included attribution credits Christopher Kerr and retains the separate Chihyu Chen notice for `020-formation_CB5.mpr`. Fixture hashes and source paths are recorded in the manifest. These are public test artifacts, not a substitute for the user's measurement corpus or an independent certification of their acquisition history.
