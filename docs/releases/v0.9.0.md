# Cyclara 0.9.0

Free software (GPL-3.0-or-later) that turns battery cycling data into checked numbers and journal-ready figures. It reads BioLogic EC-Lab `.mpr` and `.mpt` files, LANHE (LAND) `.cex` files, and the text or Excel exports of Arbin, Maccor, Neware, BaSyTec, Novonix, PEC and Landt cyclers, and learns any other cycler's export from one file.

## New in 0.9.0

- **LANHE (LAND) `.cex` files open directly.** Drop the tester's own file on the window. Cyclara checks its reading of each file against the tester's own records wherever the file holds enough of them: the current against its capacity counter, the voltage against its energy counter, the record time against its clock; a note says when a file is too short for a check. A `.cex` of a kind not seen before (another layout, step type, status event or unit kind, or a range code its own counters cannot confirm) is refused with the reason instead of being guessed. The tester's step table comes with the export as `instrument_steps.csv`. Verified on one real file; a comparison with LANHE's own Excel export of that file is still to come.
- **A step that ended at once no longer gives an efficiency.** A step that stops at its first check (a charge to a voltage limit started on a cell already beyond that limit, for example) carries almost no charge, and paired with the full branch after it gave an efficiency of millions of per cent. A pair in which one branch has at most two rows and under 0.1 % of the other's charge keeps its capacities, energies and potentials, has no efficiency, energy efficiency or hysteresis, and its note says why; when that branch is the discharge, the cycle has no retention either and is left out of the cycle reaching 80 % and the fade line. When a file opens this way, the app asks whether each cycle starts with a charge or a discharge.
- Fixed: the dQ/dE map left one panel empty when charge and discharge curves began in different cycles; a single cycle was labelled 1.50, 1.75 and so on; the bin width in the summary figure could sit over a curve; a withheld hysteresis was still drawn; a cycle cut short by the end of the file was described as having no partner branch; text exports whose rows end in a lone carriage return, and UTF-16 exports, could not be read; a binary file from another maker gave a raw error message instead of an instruction.

## Install

**Windows** 10 (version 1903 or later) or 11, 64-bit: run `Cyclara-0.9.0-Setup.exe`, then Next, Install, Finish. No administrator password is needed, and it installs over 0.8.0. The first time, SmartScreen may say "Windows protected your PC", because the installer is not signed with a paid certificate: click *More info*, then *Run anyway*.

**macOS** 14 or later: unzip `Cyclara-0.9.0-macOS-AppleSilicon.zip` (M1 to M4) or `Cyclara-0.9.0-macOS-Intel.zip`, drag Cyclara.app to Applications and open it. The first time, macOS says it cannot verify the app: click Done, then System Settings > Privacy & Security > *Open Anyway*, and open it again. On macOS 14, right-click the app and choose Open.

The handout (`Cyclara_handout_v0.9.0.pdf`) shows every step with pictures.

## Tested

The installers were built from a clean checkout of commit 36be5dd, the source of this release; the commit after it adds only these checksums, the build evidence and documentation under `docs/`, none of which is inside the installers. On that checkout all 1002 tests pass on Linux. The Windows program, run with its bundled Python under Wine, opens every view of the demonstration file and passes its own suite (981 tests); this installer, run under Wine over 0.8.0, installed a tree identical file for file to the one tested, and uninstalled cleanly. Before the build, a reviewer who had not written the new code compared every statement about it in these notes, the handout and the documentation with the code; what it found is fixed (`docs/handoffs/Project_Status_Addendum_2026-10-21.md`). Not yet run on a physical Windows PC or Mac: reports are welcome through Help > Report a problem.
