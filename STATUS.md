## Decision: free and open

The toolkit is released under GPL-3.0-or-later. It is built first as a working tool for the author's own measurements and published so others can use and inspect it. There is no commercial layer, so the GPL licence of the optional Galvani reader is compatible and no independent MPR decoder is planned.

## Validation on the author's own data (2026-09-10)

A Li metal half-cell cycled for more than 100 cycles on an MPG-2 (GCPL, EC-Lab 11.43). The measurement files are private and not in the repository, and their values are not quoted here.

- Coulombic efficiency agrees with EC-Lab's own `Efficiency/%` column to 4e-6 % for every cycle; discharge capacity agrees with EC-Lab's `Capacity/mA.h` to 6e-9 mAh (the residual is EC-Lab's single-precision display).
- The MPR binary and its 31 MB MPT export give identical results (2e-16 mAh).
- One interrupted final charge is correctly reported as unpaired, and flagged by the diagnostic for a branch passing more than three times the median charge.

## Cyclara (0.6.0, 2026-10-19)

A desktop app on the cycling engine (PySide6 6.12.0 and pyqtgraph 0.14.0, the stack of ADR-005), sharing one workflow layer (`electrochem/workflow.py`) with the command line. Design, decisions and verification: `docs/U02_Cyclara.md`.

- **Workflow.** Drop or open a file; a reading screen states only what has happened; four questions only the researcher can answer (charging direction; cycle order, when the file starts with a discharge; what the potential column measures; active-material mass or "No mass"); eight views; a cycle strip that is selector, legend and fade picture at once; export of journal-sized figures, every table, `settings.json` and an Origin folder to a new folder, never overwriting.
- **Figures.** Journal presets from the publishers' pages (Nature, Elsevier), exact widths, type 5 to 7 pt with sub- and superscripts raised to the journal minimum, panel letters 8 pt bold lowercase, legends placed where they cover nothing, and twelve checks after drawing, stored with every export.
- **Name, mark and motion.** Launch sequence, reading screen, view transitions, confirmations and a theme switch that spreads from the switch as a widening circle. All short, skippable, and reduced or off by the system's reduce-motion setting or View > Motion.
- **Windows and macOS.** Same physical type size on both, native menu bar on macOS, Desktop and Start-menu shortcuts or a `Cyclara.app` built by the setup scripts, the taskbar shows Cyclara's icon.
- **Small screens.** Works from 1024 × 600 points (a 14-inch laptop at 150 % scaling): the Overview arranges its panels for the room, axis titles shorten instead of being cut, the tables fold to their tab row (Ctrl+J), and the window opens at a size that fits the screen and reopens where it was left.
- **Independent review.** A separate agent reported 31 findings, six of them wrong results (areal labels over mAh values, efficiency points cut off the axis, cycle order never asked, current reversals netted without a step column, three-electrode files on the cell voltage, an infinite mass accepted). All 31 are fixed, each with a regression test: `docs/reviews/Cyclara_Review_2026-10-19.md`.
- **Synthetic demonstration file** (`data/demo/`, made by `scripts/make_demo_data.py`; its header and name say it is synthetic): 50 cycles with a known per-cycle answer, used by an end-to-end test (agreement to 1e-9 relative), the screenshots and the handout, so no picture shows private data.
- **Engine changes**: dQ/dE grid kept inside the measured potentials (peak prominences and widths of the upper charge peaks change; peak potentials do not); without a step column, branches end where the current changes sign; the potential column follows the configuration answer; one capacity basis for every label and value.
- **Found and worked around in pyqtgraph 0.14**: tick labels silently multiplied by 1000 after `enableAutoSIPrefix(False)`; an axis title not re-centred when its text changes.

## Other cyclers and one-click installers (0.7.0, 2026-10-20)

- **P08, implemented and tested.** `electrochem/readers/`: a typed import profile whose four conventions (current sign, direction source, capacity semantics, cycle base) have no defaults and need a line of evidence; a generic reader for delimited text and spreadsheets that collects every finding before it refuses (45 named failure modes, `docs/P08a_Import_Failure_Mode_Register.md`), measures the capacity semantics on the file and compares the instrument's counter with the integral of the current, charge and discharge separately; a proposer that maps an unknown header and asks only what no file states; a registry that remembers a confirmed instrument by its header fingerprint; and Cyclara's import review page. EC-Lab files are recognised by signature and keep the validated path untouched; readers and engine never import each other (a test enforces it). Specification: `docs/P08_Multi_Instrument_Import_Specification.md`. Which instruments are verified on real files: `docs/P08d_Instrument_Compatibility_Matrix.md` (P08d, 20 October 2026: 16 built-in profiles, each checked against a named real export; 21 public instrument files under `data/public/<vendor>/` re-checked independently by `tests/test_readers_real_files.py`; the matrix marks which dialects are verified on a shipped file, which on inspected files only, and which are recognised only). Binary formats other than `.mpr` are refused with an instruction to export text.
- **Export variants (P08e).** The same instrument exported with other columns, another order, other units or another sheet name is the same instrument: recognition rests on the time, current and voltage columns alone, the header's unit is read rather than frozen, learned profiles claim later exports by the same rule, and a renamed required column reopens the review page pre-filled from the saved profile. Verified on re-exports of the shipped Arbin and Landt files (`tests/test_readers_variants.py`).
- **Folder opening** screens text files cheaply (`looks_tabular`): notes and logs are left alone, every measurement is opened.
- **Installers.** `installer/build.py` builds `Cyclara-0.7.0-Setup.exe` (NSIS 3, per user, no administrator prompt) and `Cyclara-0.7.0-macOS-{AppleSilicon,Intel}.zip` from a checksummed CPython 3.12.15 (python-build-standalone 20261013), the pinned wheels for each platform and the toolkit; `installer/README.md`. Verified on the build machine: checksums, the private-data scan, PE and Mach-O import closure, byte-code and pure-Python import under a real 3.12, and the Windows build run end to end under Wine (the real binaries, every view of the demonstration file). Not verified: a Windows PC or a Mac in person; neither installer is code-signed.
- **Origin from any cycler.** The Origin folder (tables in Origin's import layout, the graph spec, the build script) is written from the engine's results, so it is the same for an Arbin, Neware or Landt file as for an EC-Lab one (tested). Help > Set up the Origin link installs OriginLab's originpro bridge into Cyclara's own Python once (Windows, Origin 2021+); the export message then offers Build Origin project, or the set-up when the bridge is absent.
- **In the app.** Help > Check this installation (the self-tests, run by the installed interpreter, reported in words); Help > Open the demonstration file and a *Try the demonstration* button; a log file for windowed launches (`platform_support.keep_a_log`), opened by Help > Show the error log; the home page and About no longer say EC-Lab only.

## Plateaus, large files, methods and citation (0.8.0, 20 October 2026, later the same day)

- **Several plateaus (P14, implemented and tested; not experimentally validated).** For every cycle, each dQ/dE peak gets the capacity under it, its partner in the opposite branch (paired within 200 mV, `peak_pair_window_mV`) or the status *unpaired: no counterpart within 200 mV*, and its presence across cycles (*first cycle only*, *appears from cycle k*). The branch's average potential stays energy / charge, the capacity-weighted mean of the plateau potentials. New outputs: `dqde_peaks.csv` (every cycle, 19 new columns), `dqde_pairs.csv`, `dqde_map.csv`, `summary.json` → `plateaus`, `fig6_dqde_map`, `fig7_dqde_surface` (3D), the Evolution view, the inspector's plateau block. Verified on a synthetic cell with plateaus known by construction (`tests/plateau_cell.py`): M01 sections 9 and 10, `docs/handoffs/P14_Plateaus_and_Evolution_Handoff.md`.
- **Large files (P08f).** EC-Lab text and `.mpr` through numpy fast paths, identical to the strict P03 importers on every public file (a 1 000 000-row export: 2.7 s instead of 33 s and 2.1 GB); vectorised segmentation (2 000 000 rows: 0.17 s instead of 8 s); other cyclers' exports streamed with progress and a 2 GiB limit, checked against a frozen reference of every public file. `docs/handoffs/P08f_Large_Files_Handoff.md`.
- **In the app.** Help > How the numbers are calculated (`electrochem/methods_text.py`: twelve topics in plain words and in full, the open file's settings filled in, a methods paragraph to copy; tied to the code by `tests/test_methods_text.py`); Help > Cite Cyclara (`electrochem/citation.py`: reference, BibTeX, CITATION.cff, methods sentence; `python -m electrochem.analyze --cite`; the committed `CITATION.cff` must equal the generated one); `settings.json` carries the methods paragraph and the citation.

## Fixed conventions

- Original bytes, normalised observations and derived results stay separate. Source hashes, row references, flags, revisions and processing settings are preserved.
- Never infer mass, area, current direction, reference electrode, cycle order or geometry. `Ewe` is not terminal voltage until confirmed. EC-Lab's empty-field mass default (0.001 mg) is never offered.
- Integration only over supported edges. Time resets, duplicate timestamps, missing current, error flags and current-sign changes across a programmed boundary are unsupported and reported with a reason. A programmed boundary with advancing time and unchanged direction is included. Without a step (Ns) column, a branch ends wherever the measured current changes sign.
- Direction is decided per programmed step from the net measured current, because the first row of a step still carries the previous step's ox/red flag; the flag is a cross-check and the fallback.
- The instrument's per-row dq increment is the primary charge when present (full-rate integration); the trapezoid of sampled current is reported beside it. On constant-current stages they agree to about 1e-6; on sparsely sampled constant-voltage tails the trapezoid overstates the tail, which is why dq is preferred.
- Coulombic efficiency is Q_discharge / Q_charge of the same cycle, never clipped, whichever branch starts the cycle.
- Energy and mean voltage need the potential's meaning (`--terminal-voltage` or `--reference`). Named charge/discharge, efficiency and retention need `--charge`. Neither is inferred from labels: the native reader labels the same field `Ewe/V` that the text export calls `Ecell/V`.
- A half-cell answer analyses the working-electrode column (Ewe/V) and a full-cell answer the cell voltage where a file holds both.
- Pydantic 2.13.5 for validation; Galvani revision d4a5f44 plus NumPy 2.3.5 for the optional native path, with source fingerprint and version gates.
- Unknown uncertainty is not zero. Cycles are not independent replicates.

## Known limits

- Size limits. The app and `python -m electrochem.analyze` read EC-Lab text exports of up to 2 GiB through the fast path and `.mpr` files with no size cap of their own (memory is the limit). A file the fast path hands to the strict importer (anything unusual) is held to that importer's limits: 256 MiB, and for `.mpr` 5,000,000 records, 128 fields and one data module; the strict text importer accepts declared profiles only. Other cyclers' exports: up to 2 GiB. Snapshots: 50 MiB uncompressed.
- Native versus text comparison across six public files shows 415 last-digit differences: 362 round-trip to the same binary value, 53 differ by at most four ULP after decimal parsing. This is export rounding, not an import defect. The native record is treated as the primary source where both exist.
- The one-click installers are tested under Wine (Windows) and by static checks (macOS), not yet by a user on a physical Windows PC or a Mac, and they are not code-signed, so Windows and macOS ask once before the first launch. No screen-reader test.
- The CV desktop app prototype (P12a, delivered separately; not in `main` or the installers) may carry the pyqtgraph SI-prefix defect found in Cyclara (U02, section 10); run the same test on it before it is merged.
